1. Core Desktop Principles

WDI-METHOD · ARCHITECTURE CONTRACT

Fondasi desain desktop Snapdown dibangun secara presisi untuk efisiensi coding agent. Mengeliminasi kebisingan visual dan menyediakan bahasa interaksi deterministik untuk pengembangan masa depan.

🤖 1. AI-Agent Primitives Only
Menghilangkan coretan manual manusia (freehand, panah, kurva acak). Fokus penuh pada Numbered Step Marker (1, 2, 3) yang terikat 1:1 dengan catatan temuan (`AD-1`) untuk konsumsi agent.
⚡ 2. Single Color Authority (AD-10)
100% nilai warna wajib terdaftar pada tokens.css. Penulisan hex literal di dalam kode komponen dilarang oleh lint rule demi konsistensi Light & Dark Windows.
📐 3. Height-Packed & Zero Thrash
Mengikuti aturan UX FR-29: tinggi kontainer menyesuaikan isi sebenarnya (packed by content height), mencegah ruang kosong buatan atau scrollbar yang tidak perlu.
🎯 4. Fractional Coordinates (AD-3)
Koordinat marker dan crop area disimpan sebagai persentase fraksional (0.0..1.0) dari gambar, kebal terhadap DPI scaling dan perubahan ukuran window.

5. Frameless Desktop Architecture & Custom Chrome

TAURI V2 · FRAMELESS APIS & DRAG REGIONS

Aplikasi Snapdown berjalan dalam mode Frameless / Custom Titlebar (tanpa baris header OS default). Seluruh interaksi window dragging, minimizing, maximizing, dan closing dikontrol langsung melalui token dan komponen chrome internal:

🪟 1. Custom Drag Region (data-tauri-drag-region)
Area titlebar mengusung atribut data-tauri-drag-region yang memungkinkan reviewer memindahkan posisi window secara mulus. Elemen interaktif (tombol/input) di dalamnya wajib memiliki pointer-events: auto agar tetap dapat diklik.
🖱️ 2. Windows 11 Native Control Micro-interactions
Tombol minimize (🗕), maximize/restore (🗖), dan close (✕) memiliki lebar presisi 44px dengan efek hover semantik (Close button berubah merah #dc2626 dengan teks putih).
📐 3. App Window Border & Elevation
Pada window frameless, batas luar diberikan garis border halus 1px solid var(--color-border) dengan border-radius: var(--radius-sm) dan bayangan elevasi var(--shadow-xl) agar tegas di atas window lain.
