# Brief for W5-S2: Go Web Service with Embedded SQLite, Staged Publish, and Public Routes

## Objective
Implement container `web-api` (LC-023 `publication-router`, LC-024 `served-publication-store`) as a standalone Go service in `apps/web-service` providing embedded SQLite storage, staging upload protocol, credential-gated admin routes, and public read routes with NFR-15 identical 404 refusals (AD-4, AD-5, AD-7, AD-8, AD-9, NFR-10, NFR-14, NFR-15, BR-89, BR-91, BR-92, BR-93, BR-94, BR-101, BR-102).

## Scope & Changes Required
1. **Directory `apps/web-service`**:
   - `go.mod`: module `github.com/wiradigitalid/snapdown/apps/web-service`, Go 1.22+.
     Dependencies: `github.com/go-chi/chi/v5`, `modernc.org/sqlite` (pure Go SQLite).

2. **Storage (`apps/web-service/internal/store/`)**:
   - Embedded SQLite schema (`web_schema_version`, `published_bundle`, `published_blob`) matching `inventory-db.md` (tables 10, 11, 12).
   - Blob filesystem directory under configured data root (`DATA_DIR` / `./data`).
   - Staging table or staging directory to hold uploaded files before making slug live (BR-89).
   - Table `published_bundle`: `slug TEXT PRIMARY KEY, markdown TEXT NOT NULL, blob_dir TEXT NOT NULL, created_at TEXT NOT NULL, deleted_at TEXT`. Zero library ID columns (AD-8, BR-101).
   - Table `published_blob`: `id TEXT PRIMARY KEY, slug TEXT NOT NULL, filename TEXT NOT NULL, content_type TEXT NOT NULL, byte_size INTEGER NOT NULL, FOREIGN KEY(slug) REFERENCES published_bundle(slug) ON DELETE CASCADE`.

3. **HTTP Server & Router (`apps/web-service/internal/server/`)**:
   - Authentication middleware verifying publish credential (`PUBLISH_KEY` env or `Authorization: Bearer <secret>`).
   - Routes:
     - `PUT /publish/{slug}`: Credential-gated. Accepts JSON payload or multipart with `{ "markdown": "...", "files": [ { "filename": "...", "data_base64": "..." } ] }` (or multi-file staging). Staged all-or-nothing: atomic transition to live once all files are verified (BR-89).
     - `DELETE /publish/{slug}`: Credential-gated. Removes markdown and blobs from disk and database (BR-94).
     - `GET /publish/{slug}`: Credential-gated. Returns `{ "slug": "...", "status": "served" }` or 404 (reconcile endpoint 14).
     - `GET /b/{slug}`: Public read. Content negotiation: if `Accept: text/markdown` or `Accept: text/plain` -> returns raw Markdown verbatim (AD-9, BR-91). If browser (`Accept: text/html`) -> serves simple embedded HTML reader wrapper (or `web-ui` static bundle) (BR-93).
     - `GET /b/{slug}/raw.md`: Public read. Returns verbatim Markdown bytes unconditionally (BR-91).
     - `GET /b/{slug}/images/{filename}`: Public read. Serves image blob bytes with `Content-Type: image/png` (AD-4, BR-92). Refuses path traversals with 400 `bad_request`.
     - 404 Refusal Invariant: Unknown, deleted/revoked, or never-issued slug returns IDENTICAL HTTP 404 response body and headers (NFR-15).
     - Zero access logging of slugs paired with client addresses (BR-102).

4. **Integration Tests (`apps/web-service/internal/server_test.go`)**:
   - Test suite with `httptest.Server`:
     - Staged publish -> query `/b/{slug}/raw.md` -> verify verbatim markdown.
     - Query `/b/{slug}/images/{filename}` -> verify image bytes.
     - Unpublish -> verify slug immediately yields identical 404 response.
     - Reconcile endpoint returns accurate status.
     - Traversal refusal test.
