# Brief for W4-S4: Settings Agent Access UI Screen and Tauri IPC Commands

## Objective
Implement LC-019 `agent-access-panel` (Screen 13 in `inventory-screen.md`) and Tauri backend IPC commands to generate/re-copy/revoke the AccessKey, view key active status/timestamp, and connect local agents (BR-73, BR-74, BR-75, BR-76, UC-17, UC-19).

## Scope & Changes Required
1. **Tauri IPC Commands (`apps/desktop/src-tauri/src/commands/agent_access.rs`)**:
   - `get_access_key_status`: Returns `{ has_active_key: bool, issued_at: Option<String>, key_id: Option<String> }` (BR-74).
   - `generate_access_key`: Generates new high-entropy secret token (`sd_key_...`), calculates SHA-256 hash, stores in `access_key` table (automatically revoking any previous active key), saves secret in memory or Windows credential store / returns secret token once for display/copy (BR-73).
   - `copy_access_key`: Copies active secret to OS clipboard if stored or re-copies secret (or returns secret string for frontend clipboard copy).
   - `revoke_access_key`: Revokes currently active key. Harmless if no active key (BR-75). Does not change or delete findings/bundles (BR-76).
   - Export commands and register in `apps/desktop/src-tauri/src/lib.rs`.

2. **Frontend UI Components**:
   - `web/ui/src/screens/AgentAccessView.tsx`:
     - Render active key status: Active badge, issued timestamp, or "No active key" empty state.
     - Action buttons: "Generate Access Key" (primary), "Copy Key", "Revoke Key" (destructive/outline).
     - Display newly generated key modal/banner with copy button and hint: "Paste this key into your AI agent session with tool mcp:set_access_key".
     - Export from `web/ui/src/index.ts`.
   - `apps/desktop/src/services/agent_access.ts`: Tauri invoke wrappers.
   - `apps/desktop/src/components/AgentAccessView.tsx`: Integrate in Desktop webview tabs / settings navigation.
   - `apps/desktop/src/test/agent_access_view.test.tsx`: Vitest tests for view rendering, key generation, and revocation.

3. **Verification**:
   - Run `npm --prefix web/ui run typecheck`, `npm --prefix web/ui run lint`, `npm --prefix web/ui run test`.
   - Run `npm --prefix apps/desktop run typecheck`, `npm --prefix apps/desktop run lint`, `npm --prefix apps/desktop run test`.
   - Run `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`.
