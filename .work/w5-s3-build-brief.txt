# Brief for W5-S3: Desktop Publish Client and Tauri IPC Commands

## Objective
Implement LC-020 `publish-client` in `apps/desktop/src-tauri` and Tauri IPC commands (`publish_bundle`, `unpublish_bundle`, `get_publication_status`, `reconcile_publication`) communicating with `web-api` over HTTPS/HTTP with publish credentials and sticky error tracking (AD-5, AD-6, AD-7, AD-8, AD-9, BR-19, BR-20, BR-21, BR-23, BR-86, BR-87, BR-88, BR-89, BR-90, BR-96, BR-97, BR-98, BR-99, BR-100).

## Scope & Changes Required
1. **Desktop Publish Client (`apps/desktop/src-tauri/src/publish/`)**:
   - `client.rs`:
     - `PublishClient`: Takes base URL (e.g. `http://127.0.0.1:18500` or configured web-api) and secret publish token.
     - `publish_bundle(bundle, files)`: Reads stored Markdown bytes and burned image files from `VaultBlobStore`. Staged upload calling `PUT /publish/{slug}` with payload `{ "markdown": "...", "files": [...] }`. If upload fails, reports error and leaves local state unpublished (BR-19). If success, persists `publication` record via `PublicationStore`.
     - `unpublish_bundle(slug)`: Calls `DELETE /publish/{slug}`. Then calls `GET /publish/{slug}` to verify it is gone (reconcile check). If unpublish call fails, marks `publication.last_error = Some("...")` and KEEPS bundle marked published (BR-20, BR-96, BR-97). If confirmed, marks `unpublished_at`.
     - `reconcile_publication(slug)`: Calls `GET /publish/{slug}`. Returns whether slug is actively served on remote.
   - `mod.rs`: Export publish client structs and error types.

2. **Integration in Tauri Commands (`apps/desktop/src-tauri/src/commands/sharing.rs`)**:
   - `publish_bundle(bundle_id: String)`: Finds bundle, gets or generates 160-bit slug, collects burned images from `bundle_item` records in vault, executes publish, saves publication status.
   - `unpublish_bundle(bundle_id: String)`: Looks up publication by bundle_id, executes unpublish against `web-api`, updates store.
   - `get_publication_status(bundle_id: String)`: Returns `{ is_published: bool, slug: Option<String>, url: Option<String>, published_at: Option<String>, last_error: Option<String> }`.
   - `reconcile_publication(bundle_id: String)`: Checks remote service for status.
   - In `delete_bundle` (`apps/desktop/src-tauri/src/commands/bundle.rs`): Automatically invoke unpublish if bundle is currently published (BR-23).
   - Register commands in `apps/desktop/src-tauri/src/lib.rs`.

3. **Integration Tests (`apps/desktop/src-tauri/tests/test_publish_client.rs`)**:
   - Integration tests with embedded `tiny_http` server:
     - Successful staged publish -> verifies payload sent and publication record created.
     - Failed publish -> verifies local state stays unpublished.
     - Unpublish network error -> verifies sticky `last_error` is saved and bundle stays published locally.
     - Reconcile verification.
