# Brief for W4-S2: Local API HTTP Server with Constant-Time Auth and Bundle Routes

## Objective
Implement LC-017 `local-api-server` bound strictly to loopback (`127.0.0.1`) serving read-only Bundle routes with constant-time AccessKey validation and standard JSON error envelopes (AD-4, AD-5, AD-7, AD-9, NFR-9, BR-77, BR-78, BR-79, BR-82, BR-83, BR-84, BR-85).

## Scope & Changes Required
1. **Dependencies**:
   - Add `tiny_http = "0.12"` to workspace and `apps/desktop/src-tauri/Cargo.toml` (or appropriate lightweight HTTP crate).
   - Add `subtle = "2.6"` or use existing domain constant-time comparison.

2. **`apps/desktop/src-tauri/src/server/`**:
   - `error.rs`: Standard JSON error envelope matching `cross-cutting.md`:
     ```json
     {
       "error": {
         "code": "key_required",
         "message": "...",
         "detail": null,
         "request_id": "UUIDv7"
       }
     }
     ```
     Catalogue codes: `key_required` (401), `key_invalid` (401), `not_found` (404), `bad_request` (400), `not_allowed` (403), `unavailable` (503).
   - `auth.rs`: Middleware / extractor verifying `Authorization: Bearer <secret>` or `X-Snapdown-Key: <secret>`. Calls `access_key_store.verify_key(secret)`. Returns `key_required` if header missing/empty, `key_invalid` if hash check fails or key revoked.
   - `handlers.rs`:
     - `GET /v1/health`: Unauthenticated. Returns `{"status":"ok"}` with custom header `X-Snapdown-Service: local-api`. Reveals ZERO library info (BR-79).
     - `GET /v1/bundles`: Authenticated. Returns JSON list of bundles: `[{"id": "...", "name": "...", "finding_count": N, "composed_at": "..."}]` (BR-82).
     - `GET /v1/bundles/:id`: Authenticated. Returns exact verbatim stored `markdown` (AD-9, BR-83) and list of referenced image filenames `images`.
     - `GET /v1/bundles/:id/images/:filename`: Authenticated. Serves image bytes. Refuses paths containing `..`, `/`, `\`, or resolving outside the bundle's image folder with `bad_request` (BR-84). If image missing, returns 404 with code `not_found` (BR-85).
     - Any method other than GET (POST, PUT, DELETE, PATCH): Refused with 403 `not_allowed` (AD-5).
   - `mod.rs`: `LocalApiServer` lifecycle struct. Spawns background thread on `127.0.0.1:0` (or configured port), writes assigned port to port file or state, and provides graceful shutdown.

3. **Tests**:
   - Integration tests in `apps/desktop/src-tauri/tests/test_local_api_server.rs` testing all routes, auth refusals vs valid reads, path traversal guard, and loopback verification.
