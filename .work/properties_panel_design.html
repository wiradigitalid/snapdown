📐 Properties Panel Ergonomics & Token Sticky Layout

Solusi desain UI/UX: Sticky Bottom Token Cost + Desain Tenang untuk Tombol Hapus Screenshot (Anti-Eye Strain)

🎯 Problem & Architectural Solution

1. Sticky Bottom Token Estimator: Ketika daftar Step Marker bertambah banyak (atau kosong 0 marker), panel tengah akan melakukan scroll vertikal mandiri. Area Estimated LLM Cost dan Action Footer dikunci secara flex-shrink: 0; position: sticky; bottom: 0; di bagian paling bawah panel. Pengguna selalu melihat biaya token tanpa perlu scroll ke bawah.

2. Tombol Hapus Anti-Sakit Mata (Calm Ergonomics): Tombol hapus merah mencolok secara psikologis menimbulkan alarm fatigue dan mengganggu fokus saat bekerja berjam-jam. Di bawah adalah 3 varian desain tombol hapus untuk dipilih:

Varian A: Quiet Ghost Button (Direkomendasikan ⭐) Best Practice

Normal: Teks & icon berwarna muted slate (abu-abu tenang) tanpa border menyala.
Hover: Berubah lembut ke latar soft rose (--color-danger-subtle) dengan teks merah marun. Tidak mencolok di mata, namun tegas saat diarahkan kursor.

Varian B: Subdued Neutral Pill Secondary Style

Normal: Memiliki border tipis sunken neutral mirip tombol secondary biasa.
Hover: Berubah menjadi danger border dan danger text. Sangat rapi dan terstruktur di grid footer.

Varian C: Loud Red Border (Desain Lama) Loud / Eye-strain

Border merah dan teks merah menyala terus-menerus. Terasa terlalu agresif untuk screenshot queue rutin.

⚡ Micro-interactions & Usability Highlights
  • Independensi Scroll: Observation Summary (130px) + Step Marker Notes bergerak bersama di viewport scroll tengah, sementara Header dan Token Footer tetap diam di posisinya.
  • Zero Jitter: Tidak ada layout shift saat marker ditambahkan dari 0 ke 5+.
  • Konfirmasi Lembut: Hover pada tombol hapus memberi feedback visual langsung tanpa pop-up yang mengganggu flow kerja.
