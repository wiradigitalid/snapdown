# Brief for W5-S1: SQLite schema migration v5 (publication) and PublicationStore

## Objective
Implement `publication` database migration v5, domain model `Publication`, repository port `PublicationStore`, and SQLite implementation `SqlitePublicationStore` in `snapdown-core` and `snapdown-store` (AD-8, BR-20, BR-21, BR-22, BR-90, BR-96, BR-97).

## Scope & Changes Required
1. **`crates/snapdown-core/src/domain/publication.rs`**:
   - Create `Publication` entity struct:
     ```rust
     pub struct Publication {
         pub id: String,
         pub bundle_id: String,
         pub slug: String,
         pub base_url: String,
         pub published_at: String,
         pub unpublished_at: Option<String>,
         pub last_error: Option<String>,
     }
     ```
   - Implement `Publication::generate_slug()`: 160 bits from CSPRNG, lowercase base32/alphanumeric without padding (e.g. 32 characters, no library ID leaks per AD-8).
   - Export in `crates/snapdown-core/src/domain/mod.rs` and `crates/snapdown-core/src/lib.rs`.

2. **`crates/snapdown-core/src/ports/publication_store.rs`**:
   - Define trait `PublicationStore: Send + Sync`:
     - `fn get_by_bundle_id(&self, bundle_id: &str) -> Result<Option<Publication>, StoreError>`
     - `fn get_by_slug(&self, slug: &str) -> Result<Option<Publication>, StoreError>`
     - `fn save(&self, publication: &Publication) -> Result<(), StoreError>`
     - `fn mark_unpublished(&self, bundle_id: &str, unpublished_at: &str) -> Result<(), StoreError>`
     - `fn set_last_error(&self, bundle_id: &str, error: Option<&str>) -> Result<(), StoreError>`
     - `fn delete_by_bundle_id(&self, bundle_id: &str) -> Result<(), StoreError>`
     - `fn list_active(&self) -> Result<Vec<Publication>, StoreError>`
   - Export in `crates/snapdown-core/src/ports/mod.rs`.

3. **`crates/snapdown-store/src/sqlite/migrations.rs`**:
   - Add Migration 5:
     ```sql
     CREATE TABLE IF NOT EXISTS publication (
         id TEXT PRIMARY KEY,
         bundle_id TEXT NOT NULL UNIQUE,
         slug TEXT NOT NULL UNIQUE,
         base_url TEXT NOT NULL,
         published_at TEXT NOT NULL,
         unpublished_at TEXT,
         last_error TEXT,
         FOREIGN KEY(bundle_id) REFERENCES bundle(id) ON DELETE CASCADE
     );
     ```

4. **`crates/snapdown-store/src/sqlite/publication_store.rs`**:
   - Implement `SqlitePublicationStore` wrapping connection handle with transactional guarantees.
   - Update `.constitution/project/inventory-readers.py` for table `publication` if needed.
   - Export in `crates/snapdown-store/src/sqlite/mod.rs` and `crates/snapdown-store/src/lib.rs`.

5. **`crates/snapdown-store/tests/test_sqlite_publications.rs`**:
   - Integration tests verifying migration v5, slug uniqueness, lifecycle (publish, republish with same slug, unpublish, sticky last_error).
